# Claude Sessions

A small local web UI to manage your [Claude Code](https://docs.claude.com/en/docs/claude-code) conversations:
browse them side by side, search inside them, rename, move, delete, and resume any of them in a terminal
with one click.

Zero dependencies: plain Node.js and a single HTML page served on `localhost`.

> Unofficial tool, not affiliated with Anthropic. It reads and writes the transcript files Claude Code keeps
> on your disk (`<config folder>/projects/**/*.jsonl`).

## Why

Claude Code keeps every conversation as a `.jsonl` file, and `claude --resume` only lists the sessions of the
current folder. Once you have dozens of sessions spread over many projects, and maybe several config folders
(for example one per account through `CLAUDE_CONFIG_DIR`), finding "that conversation where we fixed the
parser" gets tedious. Claude Sessions puts them all on one board.

## Features

- **One column per profile** (a profile = a Claude Code config folder), sessions sorted by last activity,
  with their title (generated by Claude or renamed by you), folder, id and message count.
- **Search** by title, path, id, and **inside the messages** (full text, with highlighted excerpts).
- **Read** a full conversation in a modal, with in-conversation search.
- **Rename** a session (written to the transcript exactly like a rename from Claude Code).
- **Move** a session to another profile, or **delete** it (with confirmation, side files included).
- **Resume** a session in a new terminal window: `claude --resume <id>` in the right folder.
  Shift+click adds an optional flag (by default `--allow-dangerously-skip-permissions`).
- **Usage** per profile (session and weekly limits), read through `claude --print /usage`.
  The throwaway transcripts that this command leaves behind are cleaned up automatically.

## Installation

Requirements: Node.js 18+ and Claude Code.

```bash
git clone https://github.com/JonesJugHead/claude-sessions.git
cd claude-sessions
node claude-sessions.js
```

On Windows you can also double-click `claude-sessions.cmd`.
Or install it globally with `npm install -g .` and run `claude-sessions`.

## First launch

When no configuration exists yet, a short setup runs in the terminal. Every question has a default, and
pressing Enter keeps it:

1. **Profiles**: the Claude Code config folders found on your machine (`CLAUDE_CONFIG_DIR`, `~/.claude`,
   `~/.claude-*`, `~/.config/claude`). For each one: show it or not, the column name, and the command that
   starts Claude Code (`claude` by default). You can add other folders by path.
2. **Port** of the web UI (default `4317`).
3. **Terminal** used to resume sessions, detected for your OS (Windows Terminal or Command Prompt;
   Terminal or iTerm2 on macOS; gnome-terminal, konsole, kitty, xterm... on Linux), or a custom command.
4. **Shift+click flag** (`-` to disable).
5. **Open the browser** on start or not.

Everything is saved to `~/.claude-sessions/config.json`. Run the setup again at any time:

```bash
node claude-sessions.js --setup
```

Without an interactive terminal (for example when started by another program), the detected defaults are saved
directly.

## Configuration file

```json
{
  "port": 4317,
  "profiles": [
    { "label": "Default", "configDir": "~/.claude", "command": "claude" },
    { "label": "Work", "configDir": "~/.claude-work", "command": "claude" }
  ],
  "terminal": "start \"{title}\" cmd /k \"{script}\"",
  "dangerFlag": "--allow-dangerously-skip-permissions",
  "openBrowser": true,
  "purgeUsageTranscripts": true
}
```

| Key | Purpose |
| --- | --- |
| `port` | Local port of the web UI (bound to `127.0.0.1` only). |
| `profiles[].configDir` | Claude Code config folder (`~` is expanded). |
| `profiles[].command` | Command that starts Claude Code for this profile. |
| `profiles[].setConfigDirEnv` | Set `CLAUDE_CONFIG_DIR` to `configDir` when running the command. Defaults to `true` for any folder other than `~/.claude`. |
| `profiles[].usage` | Read the usage of this profile (`true` by default). |
| `profiles[].color` | Column color (optional). |
| `terminal` | Command that opens a terminal. `{script}` is a generated script that goes to the session folder and runs `<command> --resume <id>`; `{cwd}` and `{title}` are also available. |
| `dangerFlag` | Flag added on Shift+click. Empty string to disable. |
| `openBrowser` | Open the UI in the browser on start. |
| `purgeUsageTranscripts` | Delete the transcripts left behind by `--print /usage`. |

Set `CLAUDE_SESSIONS_CONFIG` to use another configuration file.

## Security notes

- The server only listens on `127.0.0.1` and rejects requests whose `Host` is not `localhost` /
  `127.0.0.1`, as well as cross-site or non-JSON `POST` requests, so other websites cannot drive it.
- Deleting a session is permanent. The UI always asks for confirmation first.
- The Shift+click flag lets Claude Code skip permission prompts. Leave it empty if you never want it.
